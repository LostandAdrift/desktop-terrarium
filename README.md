# Desktop Terrarium

A small living world for Omarchy, shaped by the activity of your computer.

Native to Omarchy Quattro. Local by default. No account, cloud service, or AI subscription required to run it.

Development is in progress. Installation and release documentation will arrive with the first tested release.

## Development

Requires Omarchy 4, Quickshell, Python 3, and Node.js for development checks. The plugin will run within the existing Omarchy shell.
