## 0.1.0 — 2026-09-04

First public release for Omarchy Quattro.

- Original procedural garden driven by local CPU, memory, network traffic, and application groups.
- Stable resident positions, observed growth, and a bounded session journal.
- Three palettes, local-time selection, reduced motion, and a labeled demonstration.
- Native bar integration, keyboard navigation, compact layouts, and an optional click-through scene behind windows.
- One read-only observer shared by every monitor, with hidden-state shutdown, stale detection, and retry.
- No runtime accounts, network requests, command-line collection, application-content access, or saved activity history.
- Automated procfs, state-model, and QtQuick checks; opt-in native lifecycle and resource measurement tools.
